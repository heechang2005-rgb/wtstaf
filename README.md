# 갸루렌즈 ✨

안드로이드 화면에 보이는 글자를 **한국어 갸루 말투**로 바꿔서 원래 글자 위에 덮어 보여주는 앱.
영어·일본어·중국어는 번역하면서, 한국어는 말투만 바꿔요.

```
화면 캡처 → 글자 인식(ML Kit, 폰 안에서) → AI가 갸루 말투로 변환 → 원래 자리에 덮어쓰기
```

## 기능

- 떠 있는 **'갸' 말풍선**: 탭하면 지금 화면 번역, 한 번 더 탭하면 지우기, 끌어서 이동
- **실시간 모드**: 말풍선 길게 누르기 (보라색). 화면이 바뀌었을 때만 다시 번역하고, 같은 문장은 저장해 둬서 AI를 다시 부르지 않음
- **말투 세기**: 순한맛 / 보통맛 / 매운맛 + 직접 주문("부산 사투리 섞어 줘" 등)
- **AI 선택**: Gemini(무료 사용량 있음) 또는 Claude(유료, 아주 저렴)
- 화면 글자 언어: 한국어·영어 / 일본어 / 중국어
- 가로 화면(게임) 회전 대응

## APK 만들기

이 폴더는 안드로이드 프로젝트 소스예요. 설치 파일(APK)로 만드는 방법은 두 가지:

**A. GitHub에서 자동 빌드 (폰만 있어도 됨)**
1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 올린다 (`.github` 폴더 포함).
2. 올리면 자동으로 빌드가 돌아감 → 저장소의 **Actions** 탭에서 진행 확인 (5~10분).
3. 끝나면 **Releases**에 `GyaruLens.apk`가 올라옴 → 폰에서 받아서 설치
   (처음이면 "출처를 알 수 없는 앱 설치 허용"을 켜야 해요).

**B. PC의 Android Studio**
1. Android Studio → Open → 이 폴더 선택 → 동기화 기다리기
2. 폰을 USB 디버깅으로 연결하고 ▶ Run (또는 Build → Build APK)

## 처음 설정

1. 앱 열기 → **'다른 앱 위에 표시' 권한** 켜기
2. API 키 넣기
   - Gemini: https://aistudio.google.com/apikey 에서 무료 발급 (기본 모델 `gemini-3.5-flash-lite`)
   - Claude: https://platform.claude.com/settings/keys 에서 발급, 크레딧 충전 필요 (기본 모델 `claude-haiku-5-5`)
3. **API 키 테스트** 버튼으로 확인
4. **시작하기** → 화면 공유 허용
   - 안드로이드 14 이상: '전체 화면'을 고르면 어디서든 동작. '앱 하나'를 고르면 그 앱에서만 동작하는 대신, 설정의 "번역창 잠깐 숨기기"를 꺼서 깜빡임을 없앨 수 있어요.

## 알아둘 것

- 화면 글자가 Google 또는 Anthropic 서버로 전송돼요. 비밀번호·은행·개인정보 화면에서는 쓰지 마세요.
- 넷플릭스, 은행 앱처럼 캡처를 막는 앱은 화면이 검게 찍혀서 번역이 안 돼요.
- 폰을 잠그면 화면 공유가 끊길 수 있어요. 그럼 앱에서 다시 시작하면 돼요.
- Gemini 무료 사용량을 넘으면 "사용 한도" 오류가 나요. 잠깐 쉬거나 실시간 확인 간격을 늘려 주세요.
- 번역창은 살짝 투명해요. 안드로이드 12부터 불투명한 창 아래로는 터치가 막혀서, 일부러 아래 앱을 계속 조작할 수 있게 해 둔 거예요.

## 구조

| 파일 | 역할 |
|---|---|
| `MainActivity.kt` | 설정 화면, 권한, 시작/중지 |
| `CaptureService.kt` | 포그라운드 서비스: 말풍선, 실시간 모드, 전체 흐름 |
| `ScreenCapturer.kt` | MediaProjection으로 화면 프레임 받기 |
| `OcrEngine.kt` | ML Kit 글자 인식, 줄 합치기, 번역할 필요 없는 글자 거르기 |
| `Translator.kt` | Gemini / Claude 호출, 갸루 말투 프롬프트, 캐시 |
| `OverlayView.kt` | 번역문을 원래 위치에 맞춰 그리기 (글자 크기 자동 조절) |
| `Signature.kt` | 실시간 모드용 화면 변화 감지 |

빌드 환경: AGP 8.7.3 · Kotlin 2.0.21 · Gradle 8.11.1 · JDK 17 · minSdk 26 (안드로이드 8.0+)
